# v1.3

中文：新增静态 BINFBX 模型预览，支持旋转、缩放、线框与 LOD 切换；新增受限 FBX 回导及模型 MOD 打包。支持保持拓扑的整体平移、正向等比缩放和整层 UV 变换，并同步全部 LOD。不支持任意模型替换、局部变形、骨骼或动画。修复 Blender 导出兼容性。已通过离线回读和 Blender 往返测试，尚未游戏内验证。

English: Added static BINFBX preview with rotation, zoom, wireframe and LOD selection, plus restricted FBX re-import and model MOD packaging. Supports topology-preserving whole-model translation, positive uniform scaling and whole-layer UV transforms across all LODs. Arbitrary mesh replacement, deformation, rigs and animation are unsupported. Fixed Blender export compatibility. Offline read-back and Blender round-trip tests passed; in-game compatibility remains unverified.
