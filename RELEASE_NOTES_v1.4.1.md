# v1.4.1 — Bulk selection / 批量选择

中文：新增搜索框下方“全选结果”和“清空选择”，支持列表内 Ctrl+A / Ctrl+Shift+A。全选覆盖所有筛选结果，包含未显示行；清空包含隐藏选择。将“导出筛选结果”改名为“导出全部结果”，无需勾选即可批量导出。导出队列固定为开始时的结果，避免后续筛选影响任务。已验证 145,212 条索引中筛出的 29,607 条音频可一次全选，并补充中英文音频批量导出说明。

English: Added Select all and Clear selection below the search box, with Ctrl+A / Ctrl+Shift+A in the resource list. Select all checks every filtered result, including offscreen rows; Clear selection also removes hidden checks. Renamed Export filtered to Export all results to make selection-free batch export easier to find. Export jobs now snapshot their input list. Verified one-click selection of 29,607 audio entries from a 145,212-entry archive. Added bilingual audio-export instructions. Exact music-track identification and automatic bank-to-WEM/title mapping are not included.
